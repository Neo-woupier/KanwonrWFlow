# Project Skills & Capabilities Matrix (skills.md)

> **Agent AI Context:** This document serves as a comprehensive mapping of technical skills, architectural paradigms, and engineering milestones for the `KanwonrwFlow` project. It provides an automated parser or agent with the exact technical footprint of the developer (@Neo-woupier) across current and future phases.

---

## 1. Core Frontend Engineering (Current Active Phase)
The project is currently focused on building a rock-solid, production-ready user interface using cutting-edge frontend technologies.

* **Framework Proficiency:** Advanced utilization of **Next.js (App Router)** for building highly optimized Single Page Applications (SPAs).
* **Strict Type-Safety:** Implementation of **TypeScript** to enforce rigorous data modeling, preventing runtime errors and ensuring code reliability.
* **Modern Styling & Design Systems:** Leveraging **Tailwind CSS v4** combined with CSS Variables in `globals.css` to build an ultra-clean, minimalist design layout.
* **Responsive & Fluid UI:** Mastery of **Mobile-First Design** patterns, utilizing defensive design techniques (Flexbox, Grid, Dynamic Breakpoints, and Aspect-Ratios) to prevent UI distortion across varied screen sizes (Mobile, Tablet, Desktop).

---

## 2. UI/UX Extensibility & Customization (Planned Integration)
Skills focused on micro-interactions and dynamic client-side state manipulation to make the board highly user-customizable.

* **Dynamic Client Theming:** Implementation of client-side theme switching (Fonts, custom Hex color codes, and dynamic CSS styling presets).
* **Dynamic Asset Loading:** Injecting user-defined background images and custom canvas assets without breaking structural layouts.
* **Centralized State Management:** Implementing state engines (e.g., Zustand) to coordinate tasks, user preferences, and real-time interface changes smoothly.

---

## 3. Backend, Authentication & Collaboration (Future Phase)
Transitioning the product from a localized client application into a full-scale cloud platform supporting team synergy.

* **Identity & Access Management (IAM):** Integrating **Google OAuth / Social Logins** for secure, friction-free user authentication.
* **Multi-Tenant/Team Collaboration (Cowork Architecture):** Designing relational databases that allow real-time cross-user interactions (e.g., inviting teammates, assigning tasks, and shared workspace synchronization).
* **Data Modeling & ORM:** Designing relational databases with **PostgreSQL** and managing schema migrations cleanly using **Prisma ORM**.

---

## 4. Multi-Platform & Mobile Engineering (Future Phase)
Compounding web architecture knowledge to expand into the native mobile app ecosystem.

* **Hybrid Web-to-Native Wrappers:** Exploring **Capacitor.js** or **Monorepo (Turborepo + React Native)** architectures to port the Next.js frontend into cross-platform binary packages.
* **Mobile Store Compliance:** Preparing and optimizing assets, bundles, and viewports for distribution on the **Google Play Store** and **Apple App Store**.

---

## 5. DevSecOps & Security Hardening (Advanced Phase)
Ensuring the application is highly safe from malicious exploits before production deployment.

* **Penetration Testing (Pentesting):** Auditing frontend and backend routes for standard vulnerabilities (OWASP Top 10, XSS, CSRF, and SQL Injection).
* **Production Deployment:** Managing environment variables securely, setting up CI/CD pipelines, and establishing proper CORS/Security Headers.
